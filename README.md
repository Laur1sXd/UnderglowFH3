# Underglow for FH3

Customize underglow per car in **Garage → Designs and Paints → Underglow**. Preview colors and effects live, adjust brightness and speed, and recall previous setups. ANNA offers radio-reactive effects in free roam.

## Choose an edition

- **Standalone (Original)** works with FH3 Mod Platform on its own.
- **ExtraOptions** integrates with the shared ANNA menus in FH3 ExtraOptions 0.4.4 and supports NoPause and Groove Music Radio.

Both editions and their matching source ZIPs are available in [Releases](https://github.com/Laur1sXd/UnderglowFH3/releases). Install one edition.

## Install

1. Use Forza Horizon 3 Xbox One 1.0.125.0 offline in Azimuth with FH3 Mod Platform.
2. Close Azimuth and move any old Underglow DLL out of `fh3-mods`.
3. Extract the install ZIP into the Azimuth folder containing `azimuth.exe`. Keep `fh3-mods/Underglow.ini` if you are updating.
4. Start the game and open **Designs and Paints → Underglow**. Press **A (Apply)** to equip a color or effect.

See each ZIP's `Licenses` folder for credits and third-party notices.
